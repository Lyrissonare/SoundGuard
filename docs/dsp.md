# SoundGuard DSP 数学说明

所有处理为 **32-bit float 样本**，dB 运算用 `double`。唯一允许的处理是线性增益乘法
`sample *= gain`。

## 1. dBFS 峰值

```
peak   = max |x[n]|（块内）
dBFS   = 20 · log10(peak)      （peak ≤ 1e-12 时钳位到 -120）
```

## 2. 8x 超采样真实峰值（True Peak）

样本峰值只看到离散采样点；信号可能在**采样点之间**超过 0 dBFS。真实峰值通过加窗 sinc 插值重建
子采样点（ITU-R BS.1770-4 Annex 2 的思路，8x）：

```
x(i + d) = Σ_k  x[i+k] · sinc(d − k) · w(d − k)
sinc(t)  = sin(πt) / (πt)
w(t)     = 0.5 · (1 + cos(πt / K))      （Hann，K = 8，|t| < K）
```

在整数位置 `d = 0` 时 `sinc` 核精确返回 `x[i]`（不引入重建误差）。对每个样本取 8 个分数位置
（`m/8`），对全部通道取最大绝对值即得真实峰值。

## 3. ITU-R BS.1770-4 响度（LUFS）

### 3.1 K 加权

两段 IIR（RBJ 双二阶）：

| 阶段 | 类型 | 参数 |
|---|---|---|
| 1 | 高频搁架（+4 dB） | f₀ = 1681.974… Hz, Q = 0.707175… |
| 2 | 高通 | f₀ = 38.135… Hz, Q = 0.500327… |

每通道独立滤波。滤波后按 100ms 块累加均方：

```
z_c(块) = (1/N) · Σ_n [ K(x_c[n]) ]²
E(块)   = Σ_c z_c        （所有通道权重 1.0）
```

### 3.2 窗口与门限

- **Momentary**：最近 4 个块（400ms）
- **Short-term**：最近 30 个块（3s）
- **绝对门限**：丢弃 `E < 10^((-70 + 0.691)/10)` 的块（静音门）
- **相对门限**（仅 Short-term）：先按绝对门限测出未门限响度 `L`，再丢弃低于
  `10^((L − 10 + 0.691)/10)` 的块

### 3.3 响度公式

```
L = −0.691 + 10 · log10( mean(E_gated) )   （LUFS）
```

其中 `−0.691 dB` 补偿 K 加权搁架的直流增益。均值取“门限后保留块的算术平均”。

## 4. 软拐点前视限幅器（阶段 A）

纯**增益**限幅器，无波形整形、无谐波失真。软拐点曲线（C¹ 连续）：

```
x     = levelDb − thresholdDb
gain  =  0                                    , x ≤ −knee/2
       =  −x                                  , x ≥ +knee/2
       =  −(x + knee/2)² / (2·knee)           , 其它
```

增益包络用一阶平滑（attack/release 不同时间常数）：

```
coef   = exp(−1 / (τ · fs))
g[n]   = target + coef · (g[n−1] − target)     （τ 取 attack 或 release，取决于方向）
```

**前视**：输入先进一段延迟线（约 1.5ms），检测器对未延迟信号算目标增益，再把平滑后的增益施加到
延迟后的样本上——增益在峰值“到达”输出之前就已开始衰减。

**8x 超采样**用于检测器，捕捉采样点间的过冲，因此限幅器是对“真实峰值”而非“样本峰值”工作。

## 5. 响度限幅器（阶段 B）

把 3 秒短期 LUFS 映射为慢速增益：

```
target = clamp(thresholdLufs − shortTermLufs, −maxReduction, 0)
```

用块级一阶平滑（attack 150ms / release 2s）。目标恰好“削掉”超过阈值的响度量。它不逐样本处理音频，
而是把增益交给引擎用于主音量衰减。

## 6. 组合与优先级

```
combinedGR = max(peakGR, loudnessGR)
```

阶段 A（峰值）在数值上几乎总大于阶段 B（响度），因此瞬态保护天然优先——符合“阶段 A 始终优先于
阶段 B”的要求。

## 7. 单元测试校验的数学不变量

- **响度标定**：幅度 ×2 → 功率 ×4 → 响度 **+6.02 LU**（相对标度测试，与 K 加权绝对增益无关）。
- **滤波器**：高通 DC 增益 → 0；高搁架高频增益 → 10^(4/20) ≈ 1.585。
- **软拐点**：阈值处增益 = −knee/8 = −0.375 dB。
- **真实峰值**：7.5kHz@48kHz（6.4 样本/周期）样本峰值 ≈0.88，真实峰值 ≈1.0——验证超采样确实抓到
  采样点间过冲。
